## Quick orientation

Shopify work usually falls into three tracks:

1. **Theme development** — Liquid, Online Store 2.0, sections/blocks, theme app extensions  
2. **App development** — GraphQL Admin API, Polaris, App Bridge, Shopify CLI, React Router  
3. **Headless / Hydrogen** — Storefront API, Hydrogen, Oxygen, Customer Account API  

Most SMB clients still need **themes and apps**. Hydrogen is more common for larger or highly custom storefronts.

Start with [learning-path.md](./learning-path.md), then use [americas-smb-opportunity.md](./americas-smb-opportunity.md) when deciding which markets to target for freelance or agency work.

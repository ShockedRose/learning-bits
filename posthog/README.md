## Quick orientation

PostHog is an all-in-one product OS. Most learning paths cover these product areas:

1. **Product analytics** — events, insights, funnels, retention, paths  
2. **Feature flags & experiments** — rollouts, A/B tests, multivariate tests  
3. **Session replay** — watch real sessions to debug UX and conversions  
4. **Surveys & feedback** — in-app and link surveys tied to product data  
5. **Data pipeline / CDP** — capture, transform, and send data to warehouses and destinations  

Start with [learning-path.md](./learning-path.md). Use [follow-ups.md](./follow-ups.md) to track practice projects and open questions.
